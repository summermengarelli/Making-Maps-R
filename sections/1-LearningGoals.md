Learning Objectives
================

By the end of this workshop, we should be able to:

- Define GIS and the major kinds of spatial data
- Differentiate between spatial and attribute data, and understand how
  they can be combined
- Accomplish the following tasks in R:
  - Load in the *sf* and *tmap* packages, as well as U.S. Census data
  - Join spatial and attribute data
  - Create basic static and interactive maps
  - Clip spatial data to a study area

## Workshop materials

You may access the workshop materials in the
[**materials**](../materials/) folder of this repository. This folder
contains the following files:

1.  **mapping.R** – the R script in which we will practice writing code
2.  **DHC2020-P2.csv** – the attribute data from the Census Bureau,
    which we will combine with spatial data
3.  **county-commissioner/** – the folder containing the shapefile of
    St. Joseph County commissioner boundaries, which make our study area
